nuScenes-based monocular 3D visual grounding annotations prepared by
[Jss-Jmu](https://github.com/Jss-Jmu), following a dataset construction approach
inspired by [LM2CNet](https://github.com/cv516Buaa/LM2CNet).

## Downloads

| Dataset | Download |
| --- | --- |
| nuScenes-based annotations (this work, v1.0.0) | [Download JSON](https://github.com/Jss-Jmu/IF-jmu/releases/download/v1.0.0/LM2CNet.json) |
| KITTI-based Mono3DRefer (original authors) | [Original Google Drive download](https://drive.google.com/drive/folders/1ICBv0SRbRIUnl_z8DVuH8lz7KQt580EI?usp=drive_link) |
| nuScenes images and sensor data | [Official nuScenes downloads](https://www.nuscenes.org/nuscenes) |

The annotation download is `LM2CNet.json`. Images are obtained from nuScenes
separately.
