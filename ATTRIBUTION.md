# Sources and attribution

## Newly prepared nuScenes-based annotations

The annotation collection in `LM2CNet.json` was prepared by Jss-Jmu. Its dataset
construction approach was inspired by
[LM2CNet](https://github.com/cv516Buaa/LM2CNet), whose project provides dataset
construction examples for monocular 3D visual grounding.

The filename `LM2CNet.json` is retained from the local dataset. This release
distributes the annotations prepared by Jss-Jmu and does not represent an
official LM2CNet dataset release or an endorsement by its authors.

Jss-Jmu's original contributions to the annotations are
available under Creative Commons Attribution-NonCommercial-ShareAlike 4.0
International (CC BY-NC-SA 4.0). The license text is provided in `LICENSE`.
Please attribute these contributions to Jss-Jmu and link to
<https://github.com/Jss-Jmu/IF-jmu>, specifying the version used.

## nuScenes

Image references and geometric labels relate to the nuScenes dataset.
nuScenes-derived content retains its original rights and terms:

- Dataset and downloads: <https://www.nuscenes.org/nuscenes>.
- Terms: <https://www.nuscenes.org/terms-of-use>.
- Original dataset paper: <https://arxiv.org/abs/1903.11027>.

Obtain the original images and sensor data through nuScenes and follow its
applicable terms. The attribution and license for newly prepared contributions
do not replace the terms for underlying nuScenes content.

## LM2CNet

The dataset construction reference is:

- Project: <https://github.com/cv516Buaa/LM2CNet>.
- Paper title: *LM2CNet: Enhancing Monocular 3D Visual Grounding with Language
  Guided Multi-Modality Coupling Network*.

Please credit the original work when using the approach it introduced.
